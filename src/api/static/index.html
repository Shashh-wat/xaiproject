What this page does

A CNN classifies a crop leaf. Three methods explain the prediction: Grad-CAM, SHAP and LIME. Each draws a different kind of map. To compare them, each map is reduced to a 64x64 picture of the evidence for the predicted class, and two maps are compared with Pearson correlation.

The Explain tab does this for your image and shows how the result compares with the typical values for the same image and for different images. The project also trains a small Siamese encoder with supervised contrastive loss (SupCon) to link the maps. The Results tab shows how it did on images it was not trained on: it did not beat plain correlation.
