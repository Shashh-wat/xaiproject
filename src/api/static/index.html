System architecture

Top: what happens when you upload a leaf. The page sends the image to the FastAPI backend. The backend runs the CNN, then Grad-CAM, SHAP and LIME, turns each result into a 64×64 map, and returns the overlays and the correlation between the maps. Bottom: the steps run beforehand from the command line. They write the model files, tables and cached maps the app reads.

  • src/api/main.py serves this page and the API. Endpoints: /predict, /explain/gradcam, /explain/shap, /explain/lime, /compare, /correlate, /results, /health, /models.
  • The trained encoder (Siamese, SupCon) is in src/correlate. The Explain tab does not use it, because it did not beat plain correlation.

Model architecture

Top: the classifier. An image goes through one of two ImageNet backbones, which are frozen. A new linear layer, the only part trained, gives 15 class scores. Middle: the three explainers. Each makes a map for the predicted class, reduced to 64 × 64. Bottom: the small encoder that was trained to link the maps. The Explain tab does not use it.

  • Both backbones end in a 7 × 7 grid of features. Grad-CAM uses that last block: features[-1] in MobileNetV2, layer4[-1] in ResNet50.
  • SHAP (GradientExplainer) uses gradients through the whole classifier. LIME only needs the class scores for perturbed copies of the image, so it treats the classifier as a black box.
  • Sizes are read from the code: src/models/factory.py and src/correlate/encoder.py.

What this page does

A CNN classifies a crop leaf. Three methods explain the prediction: Grad-CAM, SHAP and LIME. Each draws a different kind of map. To compare them, each map is reduced to a 64x64 picture of the evidence for the predicted class, and two maps are compared with Pearson correlation.

The Explain tab does this for your image and shows how the result compares with the typical values for the same image and for different images. The project also trains a small Siamese encoder with supervised contrastive loss (SupCon) to link the maps. The Results tab shows how it did on images it was not trained on: it did not beat plain correlation.
